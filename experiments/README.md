# Expériences

Conserver ici les notes détaillées, commandes reproductibles, versions,
mesures, échecs et questions issus d'expériences minimales. Un fichier peut
être ajouté par expérience, par exemple `YYYY-MM-DD-sujet.md`.

Chaque note devrait préciser :

- l'objectif et l'hypothèse ;
- l'environnement et les versions ;
- les commandes exécutées ;
- le résultat observé ;
- la conclusion (fait vérifié, hypothèse infirmée ou question ouverte) ;
- le cas échéant, la ligne ajoutée dans `KNOWLEDGE.md`.
